# internal/triage
The project's queue of disputed pseudo-labels (phase 4 · stream X; table `triage_items`, ids `tri_<uuidv7>`, migration 0035). `Hook` is an output hook on `segments` artifacts (`cadence.segments/1`): in the transaction that marks the step done it indexes every row with `origin: pseudo-label:disputed` as an open item with the segment, its `dispute` (reason, every member's text, LID) and confidence — once per (project, segments artifact, segment), so reused outputs add nothing — and emits `triage.item_added` on topic `triage.new`. A producer's meta `{"disputed": 0}` skips reading the artifact. `List` backs `triage.list` (state, reason, pipeline run, newest first). `Get` reads one item. People resolve items in the Triage panel with `triage.accept|correct|reject` (`internal/annotation`, stream A), recorded in `resolution`.
