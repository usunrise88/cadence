# internal/server
Implements `api.StrictServerInterface` (planned operations fall through to the embedded `api.Planned` → 501) and assembles the HTTP surface: `/api/*` (the contract, with request validation against the embedded spec), `/mcp` (the MCP server of `internal/mcp`, calling back into `/api` in process), `/healthz`, `/metrics`, and the SPA for everything else. `events.list` is overridden at the non-strict layer so `Accept: text/event-stream` gets the live stream. Integration tests (`-tags integration`) run the whole plane against a throwaway Postgres.
