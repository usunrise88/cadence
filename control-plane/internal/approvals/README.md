# internal/approvals
Gated commands waiting for a person (`apr_<uuidv7>`): the stored request (method, path, query, headers without credentials or cookies, body), the actor and scope that sent it, the policy rule and reason, the estimate. `Create` (called by the command pipeline), `Lock` + `Decide` (approve with the replay's result, or deny), `SessionGrant` (a session-scoped approval allows the same operation on the same path for the rest of the agent session), `Sweep` (pending approvals older than 24 h are denied, R5). Events go to the `approvals` topic and `entity.approval.{id}`. The replay itself lives in `internal/server` (it needs the HTTP handler).
