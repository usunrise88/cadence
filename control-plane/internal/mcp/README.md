# internal/mcp
The Cadence MCP server: Streamable HTTP at `/mcp` on the official Go SDK (`github.com/modelcontextprotocol/go-sdk`). Tools are the entries of the embedded `tools.json` (written by `cmd/mcpgen`, `make gen`): implemented, non-exempt operations with the contract's curated descriptions. It owns no data and no authorisation — every tool call and resource read is an in-process request to the API handler with the caller's `Authorization`, a minted `Idempotency-Key` (MCP session + JSON-RPC id; sessionless: the client's tool-use id) and `Cadence-Tool-Call-Id` (→ `causedBy.toolCallId`). Arguments are validated against the tool's input schema first. Results are JSON text `{operation, status, data|error, etag, next, help, note}` marked as data; problems are tool errors naming `help.get errors.<slug>`; 202 passes `jobId`/`approvalId` with a hint. Resources: `project://summary` (+ `project://{p}/summary`), `selection://current` (`SelectionStore`, wave 2), `defaults://` (`DefaultsSource`, stream B), `help://{id}`. `mcptest` connects the SDK client for tests (extra headers, simulated retries). Guide: `docs/help/guides/mcp.md`.
