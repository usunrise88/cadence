# internal/jobs
Jobs on River (`riverqueue/river`, pgx driver). `Service.Enqueue(ctx, tx, Spec{Kind, ProjectID, Args})` inserts the River job and its `jobs` mirror row (`job_<uuidv7>`) in the caller's transaction and returns the `job.{id}` event to emit. In-process kinds register a `Handler` before `Start`; the worker moves the mirror through queued → running → done | failed | cancelled, stores the result (completing the River job in the same transaction) and emits `job.state_changed` / `job.progress` on `job.{id}`. `Cancel` stops a queued job at once and asks a running one to stop. `Wait` backs `jobs.wait`. `AddPeriodic` schedules internal chores (approval expiry, audit retention) on River's leader. `MigrateRiver` runs River's own migrator under the migration lock (a `storage.Migrate` step).
