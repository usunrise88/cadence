# internal/data
The minimal data entities of imports (docs/spec/08-resolutions.md R18; spec 02 "Data entities as built"). Registry data: no `projectId`, events on `entity.source.{id}`.

- **Sources** (`src_…`, `sources`): unique name, licence, kind (`public | production | synthetic`), languages, url, `trainingCleared` (false = eval-only; who cleared it and when), `archived`, `rev`. `ListSources`, `GetSource` (with utterance count, hours and the dataset versions built from it), `Edit` (description, licence, clearance; `If-Match`; archived sources refuse), `Archive` (soft; no new imports), `Ensure` (an import creates the source eval-only or reuses it — same licence and kind, not archived — adding languages it did not list). Events `source.created|edited|archived`.
- **Utterances** (`utt_…`): identity = `content_hash`, the BLAKE3 (`b3:…`) of the audio file's bytes in the content store; duration, language, speaker, sample rate, channels, bytes; owned by the first source that imported them. **Transcripts** (`trn_…`): text with origin `human | pseudo-label | model:<id>` and confidence, unique per (utterance, origin, text). `dataset_utterances`: which utterances a dataset version holds, their split and the transcript it uses. `utterance_fingerprints`: kind → value per utterance (`audio-b3` from every import; steps may add others). `ListUtterances` pages oldest first by id (`after` cursor; filters source, dataset version + split, language — `he` matches `he-IL`), `GetUtterance` by id or hash with fingerprints and memberships.
- **The `dataset` artifact** (`artifact.go`): a directory artifact with `dataset.json` (`Header`, format `cadence.dataset/1`), `manifest.jsonl` (one `Line` per utterance; `audio` is a path inside the artifact) and the audio files. `ReadArtifact` checks it strictly (unknown fields, audio paths, duplicates, counts and hours). `ContentFingerprint` = sha256 of the sorted `[audio hash, split, text]` JSON tuples.
- **The output hook** (`hook.go`): `Importer.Register(hooks)` installs `Hook` for artifact type `dataset`; `server.New` registers it with the configured CAS. Inside the step's done transaction it ensures the source, upserts utterances and transcripts (batched), writes fingerprints, and registers a frozen `dataset_version` in `dataset/<params.name | header.name | source name>` with `registry.RegisterInput.Fingerprint` = the content fingerprint, so a re-import (any order, any lineage) returns the existing version. Payload: the contract's `DatasetPayload` plus `sourceIds`, `licence`, `languages`, `artifact` (hash — what training reads), `evalOnly`, `splitRule`, `speakers`, `tags`, `lineage`. Collection tags: `source:<name>`, `locale:<x>`, the header's tags, and `eval-only` when the version is eval-only at registration.
- **Trainable** (`trainable.go`): refuses (`eval-only-dataset`, 422) a version registered `evalOnly` or one whose sources are not all cleared *now* — clearing a source makes its versions trainable without a re-import. `mixes.Normalize` and `runs.EstimateRun` call it; the phase-2 run and pipeline paths must too.
