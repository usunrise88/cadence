# internal/data
The minimal data entities of imports (docs/spec/08-resolutions.md R18; spec 02 "Data entities as built"). Registry data: no `projectId`, events on `entity.source.{id}`.

- **Sources** (`src_…`, `sources`): unique name, licence, kind (`public | production | synthetic`), languages, url, `trainingCleared` (false = eval-only; who cleared it and when), `archived`, `rev`. `ListSources`, `GetSource` (with utterance count, hours and the dataset versions built from it), `Edit` (description, licence, clearance; `If-Match`; archived sources refuse), `Archive` (soft; no new imports), `Ensure` (an import creates the source eval-only or reuses it — same licence and kind, not archived — adding languages it did not list). Events `source.created|edited|archived`.
- **Utterances** (`utt_…`): identity = `content_hash`, the BLAKE3 (`b3:…`) of the audio file's bytes in the content store; duration, language, speaker, sample rate, channels, bytes; owned by the first source that imported them. **Transcripts** (`trn_…`): text with origin `human | pseudo-label | model:<id>` and confidence, unique per (utterance, origin, text). `dataset_utterances`: which utterances a dataset version holds, their split and the transcript it uses. `utterance_fingerprints`: kind → value per utterance (`audio-b3` from every import; steps may add others). `ListUtterances` pages oldest first by id (`after` cursor; filters source, dataset version + split, language — `he` matches `he-IL`), `GetUtterance` by id or hash with fingerprints and memberships.
- **The `dataset` artifact** (`artifact.go`): a directory artifact with `dataset.json` (`Header`, format `cadence.dataset/1`), `manifest.jsonl` (one `Line` per utterance; `audio` is a path inside the artifact) and the audio files. `ReadArtifact` checks it strictly (unknown fields, audio paths, duplicates, counts and hours). `ContentFingerprint` = sha256 of the sorted `[audio hash, split, text]` JSON tuples.
- **The output hook** (`hook.go`): `Importer.Register(hooks)` installs `Hook` for artifact type `dataset`; `server.New` registers it with the configured CAS. Inside the step's done transaction it ensures the source, upserts utterances and transcripts (batched), writes fingerprints, and registers a frozen `dataset_version` in `dataset/<params.name | header.name | source name>` with `registry.RegisterInput.Fingerprint` = the content fingerprint, so a re-import (any order, any lineage) returns the existing version. Payload: the contract's `DatasetPayload` plus `sourceIds`, `licence`, `languages`, `artifact` (hash — what training reads), `evalOnly`, `splitRule`, `speakers`, `tags`, `lineage`. Collection tags: `source:<name>`, `locale:<x>`, the header's tags, and `eval-only` when the version is eval-only at registration.
- **Trainable** (`trainable.go`): refuses (`eval-only-dataset`, 422) a version registered `evalOnly` or one whose sources are not all cleared *now* — clearing a source makes its versions trainable without a re-import. `mixes.Normalize` and `runs.EstimateRun` call it; the phase-2 run and pipeline paths must too.
- **TrainableArtifact** (`trainable_artifact.go`): the pipeline engine's guard on what a training step reads (run inputs at `Prepare`, resolved inputs when the step is queued). Type and meta come from the artifact index, never the caller (a different type: `validation-failed`); a `dataset` artifact must be registered by a dataset version (`eval-only-dataset` otherwise), must not be an augmented golden copy (meta `purpose: augmented`: `golden-set-leakage`), and every version registering it must pass `Trainable`; a `mix` must be a `cadence.mix/1` rendering and counts by its content — every `input_cfg` dataset version and dataset artifact — never by its meta.
- **Leakage** (`leakage.go`, phase 3): `Overlaps`, `TrainableOverlaps` and `GoldenOverlaps` count the utterances one dataset version shares with others — the same utterance, or another one with a fingerprint `(kind, value)` in common — starting from the asked side and reaching the rest through indexes (`dataset_utterances (utterance_id, version_id)`, `utterance_fingerprints (kind, value)`). `Trainable` ends with `NotGolden`: a version sharing anything with a golden set (`golden_sets`, migration 0023) fails with `golden-set-leakage`, so mixes, runs and the pipeline engine's training inputs never carry golden-set audio. `LeakageError` renders the overlaps (`errors[]` at `/overlaps/<n>`).

Phase 4 · stream D (migration 0034; docs/review/2026-10-03-phase-4-plan.md decisions 3–4):

- **Sources in full** (`sources_history.go`): `New` (`sources.new`, eval-only, a name already taken is a conflict), the licence and clearance history (`source_clearances`: created, licence, cleared, uncleared — written by `New`, `Ensure` and `Edit`) and the ingest history (`source_ingests`, one row per source of every registered dataset version), both on `GetSource`. **No licence, no ingest**: `IngestAllowed` refuses a source that is missing, archived or whose licence names none (`Unlicensed`: empty, unknown, none, NOASSERTION, n/a, tbd, …) with `source-unlicensed`; the pipeline engine applies it to every step parameter marked `x-cadence.registry: source` (`pipelines.licensed`), the draft hook again, and imports refuse such a licence too.
- **Drafts** (`draft.go`): `dataset_freeze` (mode draft) writes a `dataset` artifact of format `cadence.dataset-draft/1` — the header (source name, split rule, counts, hours, quality, stats, card) and per segment its mount URI, canonical hash (the BLAKE3 of the segment's canonical 16 kHz PCM16 WAV), size, text, origin and split; no audio. The hook registers a dataset version in state draft (`frozen: false`) with utterances, transcripts, fingerprints and memberships, the recipe (project, pipeline, commit, step kind and parameters) and the `segments` input; its fingerprint is `DraftFingerprint` over the content fingerprint and the recipe commit. `Trainable` refuses a draft with `dataset-not-frozen`.
- **Freezing** (`freeze.go`): `PlanFreeze` (the leakage check against every golden set, the cut step and its parameters) and `MarkFreezing` serve `datasets.freeze`, which starts the draft step's kind again in mode cut in the draft's project. The cut (`cadence.dataset/1` with `draftVersionId`, `quality`, `stats`, `card`, `shards`) makes the draft frozen in the hook (`completeFreeze`): the content fingerprint must equal the draft's, the leakage check runs again, and the payload gains the artifact, shards (`location: cas`), the measured quality checks and the card. `PreviewVersion` is `datasets.preview`; `ListUtterances` takes `utterances.search`'s text, speaker, origin and duration filters.
