# internal/search
The search index, its query language and saved searches (docs/spec/11-ui-panels.md "Search"; `projects.search`, `views.list|get|set`).

- **Index.** `search_documents` (migration 0007) is a projection of the outbox. `Indexer` reads committed events after its cursor (`event_cursors.search`), reloads each entity an event names through its `Source` and upserts its documents in the same transaction that advances the cursor; a restart resumes after the last committed batch, and replays are harmless because documents are reloaded, not patched. The hub wakes it; it polls every second as a fallback. `IndexHelp` replaces the help articles at start. Rebuild: `DELETE FROM search_documents; UPDATE event_cursors SET seq = 0 WHERE name = 'search'`, then restart.
- **Registering a kind.** Add a row to `Sources()` in `sources.go`: the entity kind (as in `entity.<kind>.<id>`), optional `kind:` aliases and a `Loader` that reads the entity by id and returns its `Document` (scope `project` with `ProjectID` for work, `registry`, or `instance`; ref `<kind>:<id>`; title, text, tags, status, lang, numbers for comparisons, updated). Return no documents when the entity is gone. Its events then feed the index and `kind:<kind>` accepts it; nothing else changes. Never index per-user state or anything secret.
- **Matching.** Text is normalised by `Normalize` (lower case plus per-locale folders chosen by script: Hebrew strips niqqud and folds a stub list of ktiv male/haser spellings) at index and query time. With a `LocaleFolder` (`Indexer.Folder`, the server's `Scorers`: `internal/langpacks`), `FoldFor` first folds text with the locale's scoring normalizer from its language pack — the project's pack, else the shipped one; a document's `lang`, else the locale its script suggests; a query's `lang:` or script — keeping punctuation (`textnorm.Normalizer.Fold`); then `Normalize`. Without a pack or a normalizer for the locale, `Normalize` alone. `Query.Refold` applies it to a parsed query. Words match the `simple` full-text index by prefix, or pg_trgm word similarity above 0.4 (typos, identifiers); quoted phrases match as substrings.
- **Query language.** `Parse` turns free text plus qualifiers (`kind:`, `status:`/`state:`, `lang:`, `actor:`, `updated:>…`, `project:`, `scope:`, `tag:`, `alias:`, numeric `wer<10`, `dur:2..8`) into a `Query`; an unknown or malformed qualifier is `invalid-query` (400) listing every qualifier.
- **Visibility.** `Search` runs within a `Visibility` the handler resolves from the credential first (a project token never sees another project; registry hits need registry read; instance-wide work is the admin's) and the query's scope qualifiers second. Hits are ordered current project, registry and instance, other projects, help; then full-text matches before similarity-only ones; then newest; and grouped by kind.
- **Saved searches.** `saved_views`, per actor per project; `views.set` is a pointer PUT (create without If-Match, update with it) and parses the query before saving.
