# internal/mixes
Mixes: project work with revisions (docs/spec/08-resolutions.md R13) — named groups of frozen dataset versions with weights, a sampling temperature and a replay share.

`mix_<uuidv7>`, unique name per project, `rev`; every revision's content in `mix_revisions` (a run records the revision it trained on). `Normalize` fills defaults from `defaults.yaml` (`mix.*`), resolves dataset references (`ver_…`, `@alias`, collection name → newest frozen version) and validates (frozen datasets, unique groups and datasets, ranges, a replay share needs a replay group). `ComputePreview` derives hours per language and sampling shares from dataset-version metadata only: a group's probability ∝ weight^(1/temperature) among its kind, replay groups share `replayShare`. `Service.Edit` applies a person's edit (or an agent's under the `direct` policy) as the next revision, and an agent's edit under the `draft` policy as a draft (internal/drafts); the service is the draftable kind `mix`. Events on `entity.mix.{id}`: `mix.created`, `mix.revised` (payload `{mix}` with presence and preview).
