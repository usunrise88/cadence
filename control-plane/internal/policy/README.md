# internal/policy
The policy engine and permission presets (docs/spec/08-resolutions.md R7). Presets are `control-plane/templates/presets/<name>.yaml` (embedded): `tools` rules in classes read | draft | spend | gated | forbidden, `files`, `shell`, `web`, `sandbox`. `Engine.Decide(ctx, Input{Actor, Scope, Operation, VerbClass, ProjectID, Estimate, PathParams})` answers allow | approval | deny with the rule and a reason: agents and automation get their scope's preset (first match wins, default deny); people are allowed except the `everyone` rules; an agent's spend over the remaining GPU-hours budget asks for approval: the project's (`Budget`) and, for a session's actor, the session's (`SessionBudget`, when the budget implements it). The real source is `internal/runs.Meter` (lease time on GPU cards against the project's daily budget and `budgets.agent_gpu_hours_per_session`); `StubBudget` is for tests. `RenderClaude` / `RenderOpencode` turn a preset into `.claude/settings.json` (permissions + sandbox) and opencode's `permission` block; golden files in `testdata/` (`go test ./internal/policy -update`).
