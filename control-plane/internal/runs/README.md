# internal/runs
Training runs. Phase 1 has the estimate only (`runs.new?dryRun=true`, R12 table path): steps × seconds per step from
the `estimates.training` row for (base model collection, card class, memory cap, precision), the card from the
compute entity, data volume from the referenced dataset versions, `basis: table` and ±. `init` and `gpus` are in the
request from the start (R44). Without dryRun `runs.new` answers 501 until phase 2.
