# cadence-spikes

1. Open `docs/spikes/<id>-*.md`; the brief has Goal, Setup, Steps, Acceptance, Record.
2. Time-box as stated; if the box runs out, stop and write what was learned.
3. Put every measured number and every surprise in the Result section of the brief — not in chat.
4. Set `Status:` in the brief to `done`, `failed` or `partial`.
5. Summarise in one paragraph what the spec should change; the user updates the decision log.

Never install `dockview-enterprise`; never touch the production card.
