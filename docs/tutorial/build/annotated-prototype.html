The gate says no — reading a verdict

Your Serbian checkpoint finished its evaluation, and the gate has an answer. Figure 9-1 shows the Eval report after the gate ran. Read it from the top. The header says what was compared: your checkpoint against the base model. The loop strip puts the eval at Decide, so the next move is yours, not Cadence's.

The progress line counts the cells of the eval matrix (Chapter 8): one model, one golden set, one latency profile each. Two of the 76 came from the cache. Then comes the verdict , and it is failed, although the target check passed with room to spare. The replay checks explain why.

A drop of 9.0 points on the target means little on its own. What makes it trustworthy is the interval: the whole range, from −10.1 to −8.1 points, lies below zero. Resampling the 700 test utterances a thousand times never erased the gain. Chapter 8 showed how that interval is computed.

The replay checks tell the other half. Arabic went from 16.4 % to 28.4 % word error rate, Russian from 14.9 % to 44.7 %, and thirty more languages followed. The run you trained in Chapter 7 saw only Serbian. With nothing reminding it of the languages it already knew, the model overwrote them.

How a figure like this is made

Nobody draws these boxes by hand. A figure is a short spec: which screen to open, and which elements to point at. The capture script opens that screen on a stand with a read-only key, saves the screenshot, and records where each element is. If the product moves a button, the next capture fails instead of drawing a box around nothing.

{
  "id": "gate-verdict",
  "steps": [
    { "open": "eval", "doc": "eval:{{gateEval}}", "waitFor": "[aria-label='Gate checks']" },
    { "close": "Audio" },
    { "maximize": "eval" }
  ],
  "regions": [
    { "label": "Target check", "target": "[aria-label='Gate checks'] > li", "nth": 0,
      "note": "The language you trained for. WER fell by 9.0 points …" },
    { "label": "Replay check", "target": "[aria-label='Gate checks'] > li", "nth": 2,
      "style": "warning", "note": "A language the model knew before …" }
  ]
}

The same spec renders three ways. In this edition it becomes the figure above. Inside Cadence's Help panel it becomes a tour of the live screen. On GitHub it becomes a picture and a numbered list. The notes are written once.
